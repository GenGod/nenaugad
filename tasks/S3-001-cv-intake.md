# S3-001 — приём CV: текст/txt/md/docx → приватный просмотр → ручное подтверждение

**Результат:** вошедший пользователь вставляет текст или загружает
.txt/.md/.docx; парсер без сети извлекает текст с лимитами и предупреждениями;
файл хранится приватно (ownership), просматривается и удаляется вместе с
профилем; заполнение профиля — руками на основе своего текста (никакого
авто-вывода: draft ≠ факт, ТЗ 9.3: сначала deterministic, AI — опционально
и позже).

**Не входит:** PDF-парсер (следующий срез; PDF сейчас честно отклоняется с
предложением текстовой формы), OCR, AI-извлечение (перед paid AI обязательны
бюджеты/квоты/дедлайны по AGENTS), хранение исходного бинарника (минимизация:
только извлечённый текст + метаданные), автозаполнение полей профиля.

**Контекст:** ТЗ 9.1–9.3 (лимиты 10 MB / 150k символов; DOCX — пределы
распаковки; parser без сети, без исполнения; скан/непдержка → текст/ручная
форма), 8 (файлы приватны, ownership), 4.1 (до отправки в AI — уведомление;
у нас AI нет); SP 8.

## Приёмка
1. Приём: вставка текста и загрузка .txt/.md/.docx; PDF/иное — явный отказ с
   объяснением и предложением текстовой формы; сигнатурная проверка (PK для
   docx), не по расширению.
2. Лимиты (fail-closed): ≤10 MB файл; DOCX: ≤200 entries, совокупный
   распакованный ≤20 MB (maxOutputLength), шифрованные entries — отказ;
   извлечённый текст ≤150 000 символов — иначе отказ с понятной ошибкой.
3. Парсер: только node:zlib, без сети и исполнения чего-либо; текст из
   `word/document.xml` (w:t, абзацы), XML-entity decode; пустой текст —
   предупреждение, не пустой успех.
4. Приватность/ownership: список/просмотр/удаление только владельца сессии;
   неавторизованный → 401; чужой id → 404; удаление профиля удаляет и CV.
5. UPLOADS_ENABLED: локальный явный флаг (default false = маршруты отключены,
   503); e2e включает его только в тестовой среде.
6. Тесты: unit (docx happy/зип-бомба/лимиты/pdf-отказ), integration
   (ownership, удаление), e2e (вставка → просмотр → удаление; 401).
7. Никаких AI-вызовов; текст не покидает локальную базу; журналы без содержимого.

**Риск:** высокий (upload, персональные данные) — отдельный review владельца;
активация флага — его решением при приятии.
**Откат:** UPLOADS_ENABLED=false; таблицу не сбрасывать вслепую.
