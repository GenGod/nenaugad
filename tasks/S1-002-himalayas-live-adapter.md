# S1-002 — live-адаптер Himalayas (fetch → сохранение → каталог)

**Результат:** реальный источник Himalayas импортируется в PostgreSQL и попадает
в публичный каталог карточками с атрибуцией — после включения владельцем.

**Не входит:** второй источник, worker/очередь (ручной CLI-запуск), search-endpoint,
полный detail-хостинг (полный текст не публикуется — только excerpt + backlink).

**Контекст:** утверждённая политика himalayas (d48bcfe); smoke 2026-09-24: guid = URL,
даты Unix-секунды, totalCount ~100k, excerpt отдельным полем. ТЗ 5.2, 6, 7, 14, 17;
SP 2, 7, 8.

## Приёмка
1. Транспорт только в `src/server/import/fetcher.ts` (guardrail-allowlist): pinned
   https://himalayas.app, opaque cursor с валидацией, `redirect: "error"`, таймаут,
   лимит размера, 429/5xx → классифицированные исходы.
2. Импорт соблюдает политику: отказ при disabled/pending, poll-гейт ≥86400с
   (неудачный прогон не расходует окно), retention 720ч + удаление по устареванию.
3. Cursor-walk с бюджетом страниц и чекпоинтом; бюджет-лимит = partial (без miss-
   начислений); полный проход = complete; 429/5xx не трогают записи.
4. Миграция 0002: `job_snapshots` (CHECK kind/id, только himalayas) + `import_state`;
   повторный импорт идемпотентен (version растёт только при смене смысла).
5. Карточка: excerpt (не полный текст), атрибуция «Himalayas», backlink rel=nofollow,
   зарплата в исходном виде, география без выдумок; применяются гейты проекции S1-001.
6. Отключение источника (enabled=false) убирает карточки без правки UI; ошибку БД
   снапшотов не подменяет пустой успешный статус основного каталога (логируется код).
7. Активация — отдельное решение владельца: `enabled: true` + review diff + smoke
   `scripts/smoke-himalayas.ts` + первый `npm run import:himalayas`; обновление e2e
   (счётчик каталога) — в момент активации.

**Риск:** высокий (внешний ingress, права). Отрицательные/fault-тесты обязательны.
**Откат:** `enabled: false`; таблицы 0002 остаются (provenance), записи не удаляются вслепую.
**Данные:** только публичные объявления Himalayas; резюме/профили не участвуют.
