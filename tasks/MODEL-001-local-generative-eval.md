# MODEL-001 — оценка локальной генеративной модели (решение владельца №4, пункт 2)

**Результат, честно и сразу:** на этой машине, с уже установленным CPU-рантаймом,
локальная генеративная модель размера 1.5–1.7B **не обслуживает shipped-рубрику
скоринга**. Оба кандидата без специальной обвязки «повествуют» вместо ответа
JSON (0 валидных из 6 прогонов), а с обвязкой, предзаполняющей JSON, синтаксис
появляется, но качество не годится: Spearman(scores vs ручные оценки) = **−0.156**
на 8 парах, включая 85 баллов нерелевантной дизайнерской вакансии и 85 баллов
keyword-ловушке рекрутера. Скоринг остаётся закрытым; ниже — числа и варианты.

## Железо (измерено 2026-10-02, эта машина)

- CPU: Intel i5-13450HX, 16 потоков; RAM 31.6 ГБ (12.7 ГБ свободно на момент замера).
- GPU: **NVIDIA RTX 5060 Laptop, 8 ГБ VRAM** — установленный рантайм её не
  использует: `onnxruntime-node` (пакет из `@huggingface/transformers`) несёт
  только CPU-провайдеры. CUDA/DirectML — новая зависимость, то есть отдельное
  решение владельца, а не оптимизация исполнителя.

## Вывод и рекомендация

1. **Скоринг остаётся закрытым** (AI-007 в силе) — это не «подождём, пока
   включим», а измеренный факт: 1.5–1.7B q8 на CPU этой машины рубрику не
   обслуживает ни по стабильности формата, ни по качеству ранжирования.
2. Если локальный скоринг нужен — следующий шаг требует **нового решения
   владельца по рантайму**: CUDA-провайдер для onnxruntime (или llama.cpp) на
   RTX 5060 (8 ГБ) + модель 7–8B в 4-битном кванте, затем повторный замер этой
   же матрицей (скрипт и пары уже готовы). Ожидание «в 10–30 раз быстрее»
   основано на классе железа, а не на замере — это гипотеза следующего спайка.
3. Вариант «облако» остаётся отклонённым: персональные данные не покидают
   контур (решение 2026-10-01), и число выше — аргумент за, а не против.

## Ограничения, названные честно

- Выборка мала: один профиль, 8 пар; прогоны «shipped» и «strict» — 1–3 пары
  каждый. Это первый честный срез, не бенчмарк моделей.
- Предзаполнение JSON — измеренная **обвязка**, а не свойство shipped-рубрики;
  обвязка спасает синтаксис, но не качество.
- Скорость — CPU этой машины; GPU не задействован (см. выше).
- Качество судится двумя числами: доля валидного JSON и Spearman; ручные оценки
  набора — суждение человека (A1), и на 8 парах ±0.1 к корреляции ничего не
  значит. Направление эффекта (≈0/отрицательное) устойчиво к такой погрешности.
