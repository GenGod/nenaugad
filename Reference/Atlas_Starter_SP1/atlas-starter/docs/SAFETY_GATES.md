# Защита до включения риска

| Функция | Минимальный gate | Статус в стартере |
|---|---|---|
| Реальный источник | Действующий approval на каждую операцию, контракт, polling, атрибуция, provenance, корректное закрытие | Не реализовано; синтетические записи |
| Приватный профиль | Проверенная auth-библиотека/сервис, owner из сессии, отрицательные тесты двух пользователей, удаление | Не реализовано; нет формы личных данных |
| CV | Приватное хранилище, parser без сети, file/CPU/time/ZIP limits, схема, ручное подтверждение, удаление производных | Не реализовано; upload отсутствует |
| Paid AI | Один разрешённый transport, approvals, atomic reserve, root attempts, quota, deadline, uncertain, cancellation, commit gate | Не реализовано; вызов всегда отклоняется |
| Письмо | Private CRUD/версии, evidence, проверка всего body, до одного repair, защита правок, review/copy без отправки | Не реализовано; нет модельного текста |
| Бета | Все относящиеся critical tests, ручной просмотр реальных AI-результатов, restore, наблюдаемость, kill switch, допуск владельца | Не допускается текущей конфигурацией |

Проектные лимиты SP 1.0 — не купленные квоты. Ни API key, ни bool не означают approval.
Не применять source/PII/finance права на основании generated output.

`npm run guardrails` — ограниченный статический tripwire, не firewall, не pen test,
не доказательство изоляции и не обход решений владельца.

При расширении списка разрешённых imports/transport в guardrails нужен явный
review этой функции. Проверку не отключать ради зеленого CI.

## Локальные секреты
setup создаёт случайный пароль DB в .env. Он не должен попадать в git/архив/отчёты.
Нет реальных ключей AI. Не публикуйте приложение через tunnel с личными данными.
Полезный первый security review перед beta — отдельная задача, не обещание AI.
