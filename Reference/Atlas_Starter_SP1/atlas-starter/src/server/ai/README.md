# AI ещё не подключён

`disabled.ts` не является рабочим gateway. Он всегда отклоняет генерацию.
Нет ключей, SDK, фиктивного ответа модели и сетевых вызовов.

До реализации transport обязательны SP 1.0, разделы 7–11: owner/session,
подтверждённый профиль, допуск источника и purpose, версия модели/цены/privacy,
атомарный резерв, квоты, persisted operation/attempt, общий лимит попыток,
deadline, uncertain, отмена, проверка целого текста и запрет поздней записи.

Наличие функции, интерфейса или теста disabled-gate не означает готовность этих защит.
Не превращать `LIVE_AI_ENABLED=true` в обход: текущий startup намеренно падает.
Следующая задача по AI — только после auth/profile и отдельного допуска владельца.
