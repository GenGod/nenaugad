# Atlas → Ненаугад: миграция без переписывания проекта

## 1. Разделить бренд и внутренние идентификаторы
Заменить display name, title/description, заголовок, письма интерфейса, favicon, social previews, accessible names логотипа.
Не делать глобальный search/replace по БД, localStorage, cookies, API, source IDs, идемпотентным ключам, историческим ADR и тестовым identity.
Кодовое имя Atlas в архивном документе не является багом. Новые пользовательские поверхности показывают Ненаугад.

## 2. Стили и ассеты
Подключить `nenaugad.tokens.css`, затем компоненты. Если старый код использует `--atlas-*`, временно подключить `atlas-compat.css` после новых токенов.
В новой разработке использовать `--ng-*`. Старый `atlas.tokens.css` не подключать параллельно.
Скопировать `brand/` и `icons/` в согласованный каталог public; скорректировать пути manifest.
RU-wordmark — существующий supplied PNG с фиксированными пропорциями; не набирать заново случайным serif.
EN outline-master в доступных исходниках отсутствует. Не выдавать системный текст за утверждённый EN-мастер: согласовать файл отдельно.

## 3. Компоненты
Header: logo 208 desktop / 176 mobile; на 320 px сначала убрать второстепенные пункты, не ломать имя на строки.
Карточки: должность, деньги, условия, статус, источник. Сохранить три оси: compatibility, lifecycle, personal status.
«Основание» открывает evidence; скобки логотипа не меняют результаты правил.
Во входах в письмо добавить document-edit/letter; copy/history/compare/download не означают отправку.
Переход к отклику сохраняет лицензионно разрешённый маршрут.

## 4. Состояния и доступность
Проверить 320/390/768/1440, Tab/Shift+Tab, Escape, возврат фокуса, длинные RU/EN.
Убедиться, что icon-only buttons имеют имя, важные статусы не только цветовые, и новые fixed-панели не закрывают поля.
Favicon и цвет theme не утверждают наличие готового PWA. Файл manifest — ассет для подключения; service worker не создан.

## 5. Приёмка
Публичное имя обновлено, данные/ключи не изменены, исходные значения токенов совпадают, неизвестные условия не исчезли, нет автоматической отправки.
SVG не делают сети; сборка не зависит от font CDN. Локальные шрифты проекта подключаются командой отдельно.
В репозитории обновить IMPLEMENTATION_STATUS.md реальными командами. Эта поставка сама не изменяет стартер и не разворачивает приложение.
