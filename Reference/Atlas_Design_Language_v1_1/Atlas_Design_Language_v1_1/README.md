# Atlas Design Language 1.1
## Начать здесь

Откройте **atlas-ui-kit.html** в современном браузере. Сервер и установка зависимостей для просмотра не нужны. Файл автономный: нет внешних библиотек, CDN, аналитики и сетевых запросов. Дизайн-система открывается на обзоре; верхнее меню переключает основы, компоненты, пять продуктовых экранов и состояния.

Для презентационного режима: `atlas-ui-kit.html?preview=1#results`. Чтобы посмотреть мобильную адаптацию, уменьшите окно до 390 px или используйте device emulation браузера. PNG мобильных экранов имеют размер 390×844, desktop — 1440 px по ширине с полной высотой страницы.

### Содержимое
- `ATLAS_DESIGN_LANGUAGE.md` — нормативная дизайн-спецификация: 25 разделов, продуктовая семантика, визуальный язык, сценарии, доступность, управление.
- `atlas-ui-kit.html` — интерактивная автономная витрина.
- `atlas.tokens.json` — 132 токена, структура DTCG 2025.10; reference → semantic → component.
- `atlas.tokens.css` — CSS-переменные, генерируемые из JSON.
- `atlas.components.json` — 34 компонента/паттерна со свойствами, состояниями и статусом реализации.
- `atlas.copy.ru-en.json` — 33 пары ключевых текстов RU/EN; runtime-прототип на русском.
- `screens/` — 18 визуальных представлений: 9 разделов в desktop/mobile, включая пять продуктовых экранов.
- `ui.css`, `ui.js`, `shell.html`, `build.py` — исходники и воспроизводимая сборка.
- `qa/ui-report.json`, `qa/contrast.json` — фактические результаты локальных проверок.
- `qa/validate_ui.py`, `qa/check_tokens.py` — сценарии проверки.
- `HANDOFF_PROMPT.md` — инструкция следующему исполнителю.
- `references/01_TECHNICAL_SPEC.md` — исходное продуктовое ТЗ как контекст.

### Что работает локально
Поиск по синтетическим вакансиям; режим общего/персонального каталога; вкладки совместимости; draft/apply/cancel фильтров; фильтр опубликованной зарплаты; сохранение и личные статусы; раскрытие evidence; демонстрационная проверка формы; модальные панели; переключение пустых/ошибочных состояний. Результаты фильтров и сохранение хранятся только в памяти текущей страницы.

### Что НЕ подключено
Реальное резюме, parser/LLM, вычисление совместимости, источники вакансий, авторизация, серверное сохранение, удаление настоящих данных, внешние отклики и полноценный мультиязычный интерфейс. В демо выбор компании/источника не означает наличие реального объявления. Все цитаты и суммы синтетические. Не используйте прототип для персональных документов.

Профильная форма демонстрирует проверку обязательного поля; изменения не пересчитывают фиксированную подборку. Кнопка отклика открывает пояснение вместо внешнего сайта и никогда не ставит статус «Откликнулся».

### Проверено
Node syntax check; разрешение ссылок между 132 токенами; 23 контрастные пары; 63 комбинации раздела/ширины (9×7, от 320 до 1920 px) без горизонтального переполнения, с одним H1/main; 12 интерактивных сценариев; отсутствие JS page errors в этом проходе. Скриншоты просмотрены, обнаруженные отступы/перекрытие поиска и циклический фокус панели исправлены.

Не выполнены: пользовательское тестирование, полный WCAG-аудит, ручные screen-reader тесты, Safari/Firefox/Android/iOS-проход. Проверки палитры не доказывают соответствие всего продукта WCAG.

### Повторная сборка

```sh
python build.py
python qa/check_tokens.py
node --check ui.js
python qa/validate_ui.py
```

Для последнего шага нужны Python Playwright и Chromium. Сценарий по умолчанию использует `/usr/bin/chromium`; замените путь на путь своей установки. В текущей тестовой среде политика браузера запрещала навигацию `file://`, поэтому тот же HTML был передан через `set_content`. Это не сетевое приложение.

### Шрифты и Figma
Production-пара: Source Serif 4 / Inter. В автономной витрине используются установленные шрифты и системные замены; внешних запросов за шрифтами нет. Файлы шрифтов не включены. Производственная команда подключает выбранные шрифты отдельно, проверяет лицензию, кириллицу и переносы.

Нативный `.fig` не создавался. CSS/JSON/HTML и спецификация описывают перенос в Figma и frontend; совместимость с конкретным импортирующим плагином не заявлена.
